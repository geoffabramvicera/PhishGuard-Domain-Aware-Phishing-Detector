# Security Policy

PhishGuard is an educational prototype and must not be relied on as the sole protection against phishing, malware, or credential theft.

## Known limitations

- Analysis is based primarily on URL text and learned patterns.
- No live domain reputation, DNS, WHOIS, redirect, page-content, or download analysis is performed.
- The extension manually analyzes a URL but does not automatically block it.
- False positives and false negatives are possible.

## Reporting a problem

For a public academic repository, open an issue without posting secrets, session tokens, private URLs, personal information, or working phishing links that may expose others. For any potentially sensitive vulnerability, contact the repository maintainer privately when a private contact method is listed.
